# RedeCoop Website (React)

Nova versão do site da RedeCoop RS em **React + Vite + Tailwind CSS**.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Variáveis de ambiente

Copie `.env.example` para `.env` e ajuste conforme o ambiente (dev/staging/prod).

## Rotas

| Rota | Página |
|------|--------|
| `/` | Home |
| `/historia` | Nossa História |
| `/governanca` | Governança |
| `/servicos` | Serviços |
| `/cooperativismo-de-plataforma` | Cooperativismo de Plataforma |
| `/cooperativas` | Cooperativas + catálogo |
| `/blog` | Blog |
| `/blog/:slug` | Artigo |
| `/completar-cadastro/:token` | Completar cadastro |

## Stack

- React 19 + TypeScript
- Vite 8
- Tailwind CSS 4
- React Router 7
- Framer Motion
- React Hot Toast
- Lucide Icons
